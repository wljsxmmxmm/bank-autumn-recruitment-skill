# 个性化银行秋招投递表示例

## 示例用户画像

用户事实:
- 2027 届硕士，统计/计算机交叉背景，本科有金融课程基础。
- 目标城市: 上海优先，长三角可接受。
- 主投方向: 金融科技、数据分析、数字化运营。
- 偏好: 稳定性 40%，成长性 35%，城市 25%；不优先柜面和纯营销。
- 经历证据: Python/SQL 数据项目、金融科技课程项目、一段数据分析实习，暂无银行实习。

咨询判断:
- 六大行科技/数据条线和上海本地城商行是主盘。
- 股份行金融科技作为重点冲刺，但要强化业务结果和项目深挖。
- 政策性银行只做低成本冲刺，除非用户学历、宏观政策表达和党员/学生干部证据较强。

## 转外部在线文档时的字段类型

| 字段 | Notion | 腾讯/飞书/Sheets/Excel | 说明 |
|---|---|---|---|
| 银行名称 | Title | 文本 | 主键 |
| 银行类型/同类梯队/投递优先级/投递状态 | Select | 下拉单选 | 用固定枚举，便于筛选 |
| 推荐岗位方向 | Multi-select | 多选/文本 | 平台不支持多选时用逗号分隔 |
| 开始时间/截止时间/投递日期/提醒日期 | Date | 日期 | 未知日期留空，不写 `待验证` |
| 官方招聘网站/网申入口/公告链接 | URL | 超链接/URL | 保留可点击 |
| 推荐理由/主要风险/备注1/备注2 | Text | 长文本 | 保留换行 |

## 默认视图

- `P0主攻`: 中国建设银行、交通银行、上海银行、上海农商银行。
- `本周处理`: 需要核验官网、补采入口、读公告的记录。
- `截止临近`: 截止时间在 3 天内且未投。
- `流程中`: 状态为已投/测评/笔试/一面/二面/三面。
- `结果复盘`: offer、拒绝、放弃。
