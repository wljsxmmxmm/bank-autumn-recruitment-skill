# 外部在线文档转换规则

当用户确认 Markdown 银行投递表后，需要转为 Notion、腾讯文档、飞书表格、Google Sheets 或本地 Excel 时读取本文件。目标是让转换过程可控，字段类型、筛选视图、提醒和状态流转尽量一致。

## 通用流程

1. 先保留 Markdown 预览，用户确认字段和银行清单。
2. 选择目标平台: Notion / 腾讯文档 / 飞书表格 / Google Sheets / Excel。
3. 按字段映射表创建外部表格，优先使用真实日期、单选、多选、URL、长文本类型。
4. 创建默认视图: P0主攻、本周处理、截止临近、流程中、笔面试日程、结果复盘。
5. 设置提醒字段: `提醒日期`、`提醒原因`、`提醒状态`、`上次提醒时间`。
6. 创建成功后回写外部文档 URL；不要在工具调用成功前声称已创建。
7. 外部链接创建成功后，读取 `automation-playbook.md`，建议创建截止提醒、已投递进度巡检、官方公告巡检和周复盘自动化。

## 字段类型映射

| 字段 | Notion 类型 | 腾讯/飞书/Sheets/Excel 类型 | 规则 |
|---|---|---|---|
| 银行名称 | Title | 文本 | 主键字段 |
| 银行类型 | Select | 下拉单选 | 固定枚举 |
| 同类梯队 | Select | 下拉单选 | 政策性-T1、国有大行-T1 等 |
| 投递优先级 | Select | 下拉单选 | P0/P1/P2/P3/放弃 |
| 推荐岗位方向 | Multi-select | 下拉多选/文本 | 平台不支持多选时用逗号分隔文本 |
| 开始时间 | Date | 日期 | 不要写成普通文本 |
| 截止时间 | Date | 日期 | 支持排序、筛选、提醒 |
| 投递日期 | Date | 日期 | 未投留空 |
| 官方招聘网站 | URL | 超链接/URL文本 | 保留可点击链接 |
| 网申入口 | URL | 超链接/URL文本 | 找不到写待补采集 |
| 公告链接 | URL | 超链接/URL文本 | 最近一年公告 |
| 简历版本 | Select | 下拉单选 | 银行业务版/金融科技版/风控版等 |
| 投递状态 | Select | 下拉单选 | 待核验/未投/已投/测评/笔试/一面/二面/终面/offer/拒绝/放弃 |
| 笔试/一面/二面/终面 | Date 或 Text | 日期或文本 | 有确定时间用日期；未知用待通知 |
| 推荐理由/主要风险/备注 | Text | 长文本 | 保留换行 |
| 下一动作 | Text | 文本 | 自动生成或人工更新 |
| 提醒日期 | Date | 日期 | 截止前、笔面试前、投后跟进 |
| 提醒状态 | Select | 下拉单选 | 待提醒/已提醒/无需提醒/提醒失败 |

## 日期和提醒规则

- `截止时间` 已知且状态为未投/待核验: `提醒日期 = 截止时间 - 3天`。
- `截止时间` 是今天或明天: `投递优先级` 不变，但 `提醒原因=截止临近`，视图进入 `截止临近`。
- `投递日期` 已填且 7 天无反馈: `提醒日期 = 投递日期 + 7天`，`提醒原因=投后跟进`。
- `笔试/面试` 有日期: `提醒日期 = 笔试/面试日期 - 1到3天`，`提醒原因=笔面试准备`。
- 状态为 offer/拒绝/放弃: `提醒状态=无需提醒`。
- 日期未知时，不编造日期；保留 `下一动作=核验截止日期/核验笔试时间`。

## 平台规则

### Notion

- 用数据库承接主表。
- `银行名称` 用 Title；日期字段用 Date；状态和优先级用 Select；链接用 URL。
- 默认视图:
  - `P0主攻`: 筛选投递优先级=P0。
  - `本周处理`: 筛选提醒日期在未来 7 天内，状态不是 offer/拒绝/放弃。
  - `截止临近`: 筛选截止时间在未来 3 天内。
  - `流程中`: 筛选状态为已投/测评/笔试/一面/二面/终面。
  - `结果复盘`: 筛选状态为 offer/拒绝/放弃。
- 如果 Notion API 或连接器不能设置原生提醒，至少创建 `提醒日期` 和 `提醒状态` 字段，后续由每日巡检/邮件提醒模块处理。
- 创建 Notion 数据库后，优先补充 `P0主攻`、`本周处理`、`截止日历`、`流程中`、`提醒日历`、`结果复盘` 视图；有日期字段时用日历视图，不要用文本模拟日期。

### 腾讯文档 / 飞书表格 / Google Sheets / Excel

- 用第一行作为表头，启用筛选。
- 日期列必须用日期格式，不要写成 `待验证`；未知日期留空，另用备注或下一动作记录待核验。
- 单选字段用数据验证下拉: 银行类型、同类梯队、投递优先级、投递状态、提醒状态。
- URL 字段保留完整链接，必要时另设展示文本。
- 用条件格式:
  - P0 标红或高亮。
  - 截止时间 3 天内标红。
  - 投递状态=offer 标绿，拒绝/放弃标灰。
- 如平台支持提醒/自动化，用 `提醒日期` 创建日程或通知；不支持时保留提醒字段，由邮件提醒模块读取。

## 导出/导入前检查

- 日期字段是否是真日期。
- 链接字段是否可点击或保留完整 URL。
- 下拉枚举是否与 Skill 中一致。
- 是否有 `提醒日期`、`提醒状态`、`下一动作`。
- 是否保留用户确认后的银行清单，没有自动加入未确认银行。
- 是否把 `待补采集` 和 `待验证` 留在文本字段，而不是日期字段。

## Gotchas

- 不要把 Markdown 表原样复制到外部表格后就结束；字段类型才是可用性的关键。
- 不要在日期列填 `待验证`，这会破坏排序和提醒。
- 不要在外部文档创建失败时声称已创建。
- 不要让提醒只存在平台里；Skill 也要能通过 `提醒日期/提醒状态` 二次读取和发送邮件。
