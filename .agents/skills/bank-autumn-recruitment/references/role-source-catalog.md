# 投递类别与官方信息源目录

首次使用 Skill 时，先让用户选择 1-3 个投递类别。每日巡检只围绕用户选择的类别检索、核验和入表。

内置信息源只作为巡检入口和查询策略，不代表岗位一定开放。具体岗位、批次、截止日期、城市和投递链接必须在运行时实时核验。

## 投递类别

| 类别 | 适合人群 | 典型岗位关键词 |
|---|---|---|
| 总分行管培 | 想走综合培养、轮岗、管理路径 | 管理培训生、综合培养生、总行管培、分行管培、菁英计划 |
| 金融科技 | 有技术、系统、数字化或金融科技经历 | 金融科技、科技菁英、软件开发、系统运维、数字化转型、信息科技 |
| 数据分析 | 有 SQL/Python/Excel/建模/指标分析证据 | 数据分析、经营分析、商业分析、风险数据、BI、数据运营 |
| 产品经理 | 有产品、需求、用户研究、数据复盘经历 | 产品经理、数字银行产品、渠道产品、互联网金融产品 |
| 运营管理 | 有活动/用户/流程/项目推进经历 | 运营管理、渠道运营、零售运营、平台运营、用户运营 |
| 风险合规 | 金融、法律、统计、风控或合规相关 | 风险管理、授信审批、内控合规、法律合规、反洗钱 |
| 客户经理/营销 | 接受客户经营、销售服务和业绩压力 | 客户经理、财富顾问、零售金融、对公客户经理、营销岗 |
| 柜面/综合服务 | 更看重稳定、城市和确定性 | 综合柜员、运营支持、营业网点服务、综合服务 |

## 官方源分层

优先按以下顺序检索：

1. 银行官方招聘站和官方校园招聘站。
2. 总行/分行官网的人才招聘、公告公示、校园招聘栏目。
3. 银行官方公众号发布的校招公告。
4. 学校就业网、宣讲会、双选会页面。
5. 主流校招平台上的银行官方发布页面。

二手整理表、经验贴和社群转发只能作为线索，必须回到官方或平台页面核验。

## 类别检索策略

### 总分行管培

关键词:

- `2027届 银行 管理培训生 校园招聘`
- `2027届 银行 总行管培 分行管培`
- `银行 综合培养生 2027届 校招`

优先来源:

- 国有大行、股份行、政策性银行、城商行总分行官方招聘入口。
- 学校就业网中的银行宣讲会和招聘公告。

### 金融科技

关键词:

- `2027届 银行 金融科技 校园招聘`
- `银行 信息科技 科技菁英 2027届`
- `银行 数字化转型 软件开发 2027届 校招`

优先来源:

- 银行总行科技条线、金融科技子公司、官方招聘站。
- 招银网络科技、建信金融科技、银行信用卡中心和数字化部门官方入口。

## 入表规则

- `投递类别` 填用户选择的类别；一个岗位命中多类时，填最主要类别，`岗位族` 可多选。
- `来源链接` 优先写官方招聘页；公众号或学校就业网可作为通知链接，但需要继续核验投递入口。
- `官方标题` 用官方公告或岗位页面标题，不要改写成营销标题。
- `复盘记录` 写明来源层级，例如 `官方招聘站确认`、`学校就业网线索，投递入口待用户确认`。
