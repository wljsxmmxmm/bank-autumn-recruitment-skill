# 银行四级梯队投递策略

用户要求制定银行投递策略、目标银行池、梯队排序、上岸概率区间或关键时间节点时读取本文件。

## 梯队定义

| 梯队 | 银行类型 | 银行池 |
|---|---|---|
| 第一梯队 | 政策性银行 | 国家开发银行、中国进出口银行、中国农业发展银行 |
| 第二梯队 | 国有六大行 | 工商银行、农业银行、中国银行、建设银行、交通银行、邮储银行 |
| 第三梯队 | 股份制银行 | 招商银行、浦发银行、中信银行、兴业银行、光大银行、民生银行、平安银行、广发银行、华夏银行、浙商银行、恒丰银行、渤海银行 |
| 第四梯队 | 目标地域城商行/农商行 | 北京银行、上海银行、江苏银行、南京银行、宁波银行、杭州银行、徽商银行、成都银行、重庆银行、长沙银行、广州银行、苏州银行、厦门银行、青岛银行、齐鲁银行、郑州银行、西安银行、贵阳银行、兰州银行、天津银行、大连银行、盛京银行、哈尔滨银行、吉林银行、中原银行、汉口银行、湖北银行、江西银行、九江银行、福建海峡银行、桂林银行、广西北部湾银行、上海农商银行、北京农商银行、深圳农商银行、广州农商银行、重庆农商行等，按用户目标城市筛选 |

## 策略输出规则

- 每个梯队至少给 `推荐银行列表`、`投递优先级`、`上岸概率区间`、`关键时间节点`、`隐性门槛`。
- `上岸概率区间` 是相对策略判断，不是承诺；用 `高/中/低 + 区间` 表达。
- 关键时间节点涉及今年开放批次、截止日、笔试日时，必须联网核验或让用户提供链接；无法核验写 `待验证`。
- 同一家银行总行、分行、子公司、不同城市应拆开评估，不要合并成一个机会。
- 用户要求覆盖面时，先用 `scripts/generate_tracking_table.py --template comprehensive` 生成全面机会池骨架，再做城市和岗位筛选。

## 常见隐性门槛

| 银行类型 | 隐性门槛 |
|---|---|
| 政策性银行 | 学历和学校层次、党员/学生干部/宏观政策兴趣、稳定动机、笔面试综合表达 |
| 国有六大行 | 分行城市匹配、岗位服从与轮岗接受度、网申完整度、笔试通过率、稳定性 |
| 股份制银行 | 业务实习、抗压、数据化结果、客户/产品/运营意识、节奏和商业敏感度 |
| 城商行/农商行 | 本地稳定性、服务意识、地域资源、长期留存意愿、对基层或网点工作的接受度 |

## Gotchas

- 不要把梯队当成好坏排序；第四梯队可能是地域稳定用户的高优先级。
- 不要把总行和分行混为一谈；竞争强度、岗位内容和城市约束不同。
- 不要编造时间节点；银行秋招批次每年变化明显。
