# 银行同类型梯队投递策略

用户要求制定银行投递策略、目标银行池、梯队排序、上岸概率区间或关键时间节点时读取本文件。

## 梯队定义

`梯队` 是同一银行类型内部的相对层级，不做跨类型绝对排名。不要再用第一/第二/第三/第四梯队表示银行类型本身。

| 同类型梯队 | 银行类型 | 银行池 |
|---|---|---|
| 政策性-T0 | 政策性银行 | 预留给总行、核心专项、极高竞争机构或后续细分；默认机会池不强行使用 |
| 政策性-T1 | 政策性银行 | 国家开发银行、中国进出口银行、中国农业发展银行 |
| 国有大行-T0 | 国有六大行 | 预留给总行、金融市场、总行管培、核心直属机构或后续细分；默认机会池不强行使用 |
| 国有大行-T1 | 国有六大行 | 工商银行、农业银行、中国银行、建设银行、交通银行、邮储银行 |
| 股份行-T0 | 股份制银行 | 招商银行等强零售/高竞争股份行 |
| 股份行-T1 | 股份制银行 | 浦发银行、中信银行、兴业银行、光大银行、民生银行、平安银行等 |
| 股份行-T2 | 股份制银行 | 广发银行、华夏银行、浙商银行、恒丰银行、渤海银行等，按岗位和城市再判断 |
| 城商行-T0 | 城商行 | 北京银行、上海银行、江苏银行、南京银行、宁波银行、杭州银行等强区域城商行 |
| 城商行-T1 | 城商行 | 徽商银行、成都银行、重庆银行、长沙银行、广州银行、苏州银行、厦门银行、青岛银行、齐鲁银行、厦门国际银行等 |
| 城商行-T2 | 城商行 | 其他区域城商行，按目标城市、经营稳健性和岗位质量筛选 |
| 农商行-T0 | 农商行 | 上海农商银行、北京农商银行、深圳农商银行等一线/强区域农商行 |
| 农商行-T1/T2 | 农商行 | 广州农商银行、重庆农商行及其他区域农商行，按城市和岗位性质筛选 |

## 策略输出规则

- 每个同类型梯队至少给 `推荐银行列表`、`投递优先级`、`上岸概率区间`、`关键时间节点`、`隐性门槛`。
- `政策性-T0` 和 `国有大行-T0` 是 Select 预留选项，用于总行/核心专项等更高竞争机会；没有明确机构层级或岗位信息时，不要把全部政策行/六大行默认写成 T0。
- `上岸概率区间` 是相对策略判断，不是承诺；用 `高/中/低 + 区间` 表达。
- 关键时间节点涉及今年开放批次、截止日、笔试日时，必须联网核验或让用户提供链接；无法确认写 `待用户确认`。
- 同一家银行总行、分行、子公司、不同城市应拆开评估，不要合并成一个机会。
- 用户要求覆盖面时，先用 `scripts/generate_tracking_table.py --template comprehensive` 生成全面机会池骨架，再做城市和岗位筛选。

## 常见隐性门槛

| 银行类型 | 隐性门槛 |
|---|---|
| 政策性银行 | 学历和学校层次、党员/学生干部/宏观政策兴趣、稳定动机、笔面试综合表达 |
| 国有六大行 | 分行城市匹配、岗位服从与轮岗接受度、网申完整度、笔试通过率、稳定性 |
| 股份制银行 | 业务实习、抗压、数据化结果、客户/产品/运营意识、节奏和商业敏感度 |
| 城商行/农商行 | 本地稳定性、服务意识、地域资源、长期留存意愿、对基层或网点工作的接受度 |

## Gotchas

- 不要把银行类型当成梯队；城商行-T0 与国有大行-T1 是不同类型内部标签，不代表跨类型绝对高低。
- 不要把总行和分行混为一谈；竞争强度、岗位内容和城市约束不同。
- 不要编造时间节点；银行秋招批次每年变化明显。
