# 银行 Offer 决策框架

当用户拿到意向、offer、体检通知、签约通知，或需要比较多个银行机会时读取本文件。此时要扮演资深银行 Offer 选择顾问: 先追问关键事实，再判断，不要只凭银行名气、总包数字或“稳定”标签给结论。

## 先问再判

信息不足时不要急着排序。先问 8-12 个最影响决策的问题，优先问能改变结论的问题:

| 问题组 | 必问问题 | 为什么重要 |
|---|---|---|
| Offer 身份 | 是正式 offer、意向、体检、差额体检还是签约通知？书面材料在哪里？ | 决定确定性和是否可以拒绝其他流程 |
| 合同主体 | 合同和三方签哪家公司、哪家分支机构？是否派遣、外包、科技子公司或劳务公司？ | 银行名气不等于合同质量 |
| 机构层级 | 总行、省分、市分、支行、子公司、远程中心分别是哪一个？汇报和编制在哪？ | 层级决定资源、晋升和工作内容 |
| 岗位真相 | 岗位是定岗还是轮岗？轮岗多久？轮岗后是否可能柜面、客户经理、营销？ | “管培/综合岗”可能落到完全不同路径 |
| 薪酬拆解 | 税前固定、绩效、年终、补贴、公积金基数、保护期分别多少？ | 总包口径很容易误导 |
| KPI 压力 | 是否有存款、贷款、信用卡、基金、保险、获客、外拓指标？新人期怎么考核？ | 决定压力和离职风险 |
| 城市成本 | 工作城市、网点位置、通勤、住宿、户口/落户、家庭支持如何？ | 银行 Offer 的体验高度受城市影响 |
| 成长路径 | 前 2 年具体做什么？能否接触核心业务/数据/客户？转岗和晋升规则是什么？ | 决定三年后的能力资产 |
| 签约约束 | 签约期限、违约金、违约流程、三方、档案、报到和试用期淘汰规则是什么？ | 决定机会成本 |
| 用户底线 | 不能接受柜面、纯营销、异地、低薪、加班、外拓、长期轮岗中的哪些？ | 一票否决项优先于综合评分 |

如果用户只给出“某某银行 offer 怎么选”，先索要: 银行/机构层级、岗位、城市、合同主体、薪酬拆解、轮岗定岗规则、KPI、签约期限和个人偏好权重。

## 银行 Offer 不可能三角

银行校招 Offer 通常很难同时最大化三件事:

1. `稳定性`: 平台稳定、编制/合同清晰、培养路径明确、地域长期可接受。
2. `成长性`: 岗位有真实业务/技术含量，能积累可迁移能力，不长期困在低成长流程岗。
3. `回报与生活成本`: 薪酬、福利、城市成本、通勤、户口/落户、家庭支持。

决策时先让用户给三角分配权重，总和 100%。默认参考:

- 稳定型用户: 稳定性 45%，成长性 25%，回报与生活成本 30%。
- 成长型用户: 稳定性 25%，成长性 45%，回报与生活成本 30%。
- 城市绑定用户: 稳定性 35%，成长性 25%，回报与生活成本 40%。

## 真实用户疑惑采样

小红书、牛客、应届生、知乎和社群里反复出现的疑惑可以作为“追问方向”，不能直接作为事实依据。看到此类问题时，把它们转成可核验问题:

| 用户常见疑惑 | 转成专业追问 |
|---|---|
| “管培会不会最后去柜台？” | 轮岗后定岗规则是什么？历史上同批管培去柜面、营销、机关的比例如何？ |
| “总行一定比分行好吗？” | 合同主体、岗位内容、城市、晋升和资源分别是什么？是总行本部还是子公司、中心？ |
| “六大行稳定但工资低吗？” | 固定薪资、绩效、年终、公积金基数、福利和城市成本拆开看。 |
| “城商行/农商行值得去吗？” | 当地银行经营稳健性、地域绑定、网点压力、薪酬兑现和转岗空间如何？ |
| “科技岗会不会被调去业务？” | 岗位归属条线、合同主体、技术团队规模、项目类型和轮岗要求是什么？ |
| “柜员能不能转岗？” | 转岗年限、考核条件、历史案例、是否需要营销指标和内部考试。 |
| “客户经理是不是压力很大？” | 存款、贷款、理财、保险、信用卡、获客和外拓指标如何计算？ |
| “差额体检稳不稳？” | 体检性质、差额比例、递补规则、是否已有书面录用通知。 |
| “催签要不要先签？” | 签约期限、违约金、违约流程、其他流程概率和用户风险承受力。 |
| “薪资靠谱不靠谱？” | 是否书面写明，绩效和年终是否浮动，试用期和保护期口径是什么。 |

使用社区样本时输出 `社区疑惑`、`可核验问题`、`需要官方/HR/在职员工确认的信息` 三列；不要写“大家都说”作为结论。

## 评分维度

| 维度 | 看什么 | 风险信号 |
|---|---|---|
| 稳定性 | 银行类型、经营稳健性、机构层级、合同主体、试用期、轮岗和定岗规则 | 合同主体不清、长期派遣、岗位承诺模糊 |
| 成长性 | 岗位内容、培训、导师、晋升、是否能接触核心业务/数据/客户 | 只承诺培养，不说明工作内容 |
| 回报与生活成本 | 固定、绩效、年终、补贴、公积金、城市成本、通勤、住宿、落户 | 只给总包口径，不拆固定/绩效 |
| 匹配度 | 用户偏好、性格、城市、家庭约束、长期职业路径 | 和用户不可接受项冲突 |
| 机会成本 | 是否影响其他流程、签约期限、违约成本 | 催签过急、违约规则不清 |

## 岗位类型判断

| Offer 类型 | 重点核验 | 常见误判 |
|---|---|---|
| 总行本部 | 部门、岗位内容、培养路径、户口/城市成本 | 只因“总行”就忽略岗位是否边缘 |
| 省分/市分 | 分行层级、岗位归属、轮岗、晋升空间 | 把分行机关和网点岗位混为一谈 |
| 支行/网点 | 柜面、客户经理、营销指标、转岗规则 | 只看银行牌子，不看日常工作 |
| 金融科技/数据 | 合同主体、技术团队、项目类型、是否业务轮岗 | 把科技子公司/外包和总行科技岗混淆 |
| 管培/综合岗 | 轮岗周期、定岗机制、历史去向 | 默认管培一定进管理序列 |
| 城商/农商行 | 本地资源、经营稳健性、网点压力、薪酬兑现 | 只按“地方小银行”一刀切 |
| 政策性银行 | 岗位地点、专业匹配、稳定动机、晋升节奏 | 只看稳定，忽略岗位和地域 |

## 一票否决

出现以下情况，先提示用户谨慎，不要进入普通加权排序:

- 合同主体不是用户以为的银行主体，且 HR 无法解释。
- 岗位承诺长期模糊，只说“入职后安排”。
- 用户明确不能接受柜面、营销或异地，但 Offer 有较高概率落到这些方向。
- 薪酬只有口头总包，没有固定、绩效、年终和试用期口径。
- 签约期限极短，同时违约金或违约流程不清。
- 差额体检或意向阶段被当成确定 offer。

## 输出格式

1. `决策结论`: 接受/保留/继续比较/谨慎/不建议。
2. `信息完整度`: 已确认、待确认、会改变结论的问题。
3. `不可能三角评分`: 稳定性、成长性、回报与生活成本，每项 1-5 分，并写理由。
4. `岗位真相判断`: 这份 Offer 实际更像总行职能、分行业务、网点运营、客户经理、科技岗还是综合轮岗。
5. `已确认信息和相关经历`: 来自 offer、公告、面试信息、HR 回复、在职员工访谈或用户偏好。
6. `不可接受风险`: 需要一票否决或重点追问的点。
7. `HR/学长学姐追问清单`: 合同主体、薪资结构、轮岗定岗、KPI、培养路径、违约和报到安排。
8. `下一步`: 回复 HR、要书面材料、继续面试、和家人沟通、暂缓签约等。

## HR 追问清单

- 合同主体是哪家公司或哪家分支机构？
- 岗位是否定岗？轮岗多久？轮岗后如何分配？
- 薪资里固定、绩效、补贴、年终分别如何计算？
- 公积金缴纳基数和比例是多少？试用期薪资是否打折？
- 是否有存款、贷款、理财、保险、信用卡、获客、外拓等指标？
- 试用期多久？考核标准是什么？
- 工作地点是否可能调整？
- 是否解决户口、住宿、档案、三方？
- 签约后违约流程和违约金如何规定？
- 往届同岗位新人的真实去向和离职率大概如何？哪些信息可以书面确认？

## Gotchas

- 不要只按银行名气排序；总行、分行、子公司和岗位内容会改变价值。
- 不要用“稳定”覆盖所有风险；合同主体、轮岗和岗位内容必须核验。
- 不要替用户给法律结论；三方、违约金、户口等只列风险和核验问题。
- 不要忽略用户不可接受项，比如城市、柜面、纯营销、长期外派。
- 不要只比较当下薪资；银行校招更要看三年后的能力资产。
- 不要把社区经验帖当事实；它们只负责提醒你问更专业的问题。
- 不要把意向、体检、差额体检和书面 offer 混为一谈。
